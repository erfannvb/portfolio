# Developer Portfolio

A personal portfolio website built with Java, Spring Boot, and Thymeleaf to showcase my projects, technical skills, and professional experience.

## Tech Stack

- Java
- Spring Boot
- Thymeleaf
- Maven
- HTML, CSS, and JavaScript

## Features

- Professional introduction
- Technical skills and experience
- Project showcase
- Contact information

## Getting Started

Clone the repository and run the application using your IDE or Maven.
